# Jōtai – AI-Powered Productivity & Insights Dashboard

Jōtai is a futuristic, cyberpunk-themed productivity dashboard that gamifies daily tasks and integrates an intelligent personal assistant. Built with React, it includes voice-controlled goal management, performance analytics, and real-time data updates — all styled with glowing neon visuals and an RPG-style UI.

---

## 🚀 Features

- 🎙 Voice assistant integration (Gemini + Deepgram)
- 📋 Daily Quest system with visual progress tracking
- 📊 Analytics panel: streaks, completion rate, and focus time
- ⏳ Pomodoro Timer, Habit Tracker, and Inventory Notes
- 🌐 Real-time data:
  - Tech News
  - Stock Prices (Twelve Data)
  - Weather (OpenWeather)
  - Currency Exchange Rates
- 🈲 Daily Kanji learning with pronunciation (VoiceRSS)

---

## 🧠 Tech Stack

- **Frontend**: React.js, JavaScript, Custom CSS
- **APIs**: Gemini, Deepgram, Twelve Data, VoiceRSS, OpenWeather
- **State & Logic**: React Context / Hooks
